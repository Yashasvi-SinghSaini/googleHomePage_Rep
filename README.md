# Google Search Homepage - Front-End Clone

A pixel-perfect, responsive replica of the Google Search homepage built using pure HTML5 and CSS3. 

This project was created as an exercise to master fundamental layout techniques, precise element alignment, and modern CSS styling without relying on external frameworks or libraries.

## 🎯 Key Learning Objectives & Features

* **Flexbox Centering:** Mastered centering main content vertically and horizontally within the viewport using CSS Flexbox.
* **Navigation Bar & Footer Layout:** Built clean top navigation and fixed/sticky bottom footers with properly spaced links.
* **Custom Form Elements:** Styled input fields with rounded borders, hover/focus states, and embedded search/mic icons.
* **Semantic HTML5:** Structured content cleanly using semantic elements like `<header>`, `<main>`, `<nav>`, `<form>`, and `<footer>`.
* **Responsive Design:** Ensured the layout scales smoothly across various screen sizes.
